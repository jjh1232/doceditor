요즘 관공서나 학교에서 오는 문서 중에는 확장자가 `.hwp` 가 아니라 `.hwpx` 인 것이 늘었습니다.
둘 다 한글 문서지만 안쪽 구조가 완전히 다릅니다.

## hwp 와 hwpx 의 차이

| | hwp | hwpx |
|---|---|---|
| 구조 | 한컴 고유의 이진 형식 | zip 묶음 안에 XML 문서 |
| 나온 순서 | 오래 써 온 기본 형식 | 그 뒤에 나온 개방형 형식 |
| 다른 프로그램에서 읽기 | 형식 문서를 보고 직접 해석해야 함 | XML 이라 비교적 쉬움 |

hwpx 는 문서 내용을 누구나 읽을 수 있는 XML 로 담는 개방형 형식입니다.
그래서 공공기관 문서가 점점 hwpx 로 바뀌고 있습니다. 내용과 모양은 같아도 파일 안쪽이 다르다 보니,
**hwp 만 읽던 오래된 한글이나 뷰어에서는 hwpx 가 안 열리는** 일이 생깁니다.

## hwpx 가 안 열릴 때

- **한글 프로그램이 오래된 버전** — 최신 한글로 업데이트하면 열립니다.
- **한글이 아예 없는 컴퓨터·맥·휴대폰** — 브라우저로 여는 방법이 가장 빠릅니다.

[hwp 열기·편집 도구](../ko) 는 hwp 와 hwpx 를 모두 엽니다. 확장자를 보지 않고 파일 안을 읽어 형식을 판별하므로,
이름이 잘못 붙어 있어도 열립니다.

1. 파일을 끌어다 놓거나 눌러서 고릅니다. 화면에 「한글(hwpx) 문서입니다」 처럼 형식이 표시됩니다.
2. 빈칸에 글자를 채웁니다.
3. **「hwpx 로 저장」** 을 누르면 같은 hwpx 형식으로 저장됩니다.

## hwpx 에서 아직 안 되는 것

hwpx 문서는 지금 **글자 채우기만** 됩니다. 사진·서명 넣기와 글자 크기 바꾸기는 hwp 문서에서만 됩니다.
또 이 도구는 형식을 바꾸지 않습니다. hwpx 는 hwpx 로, hwp 는 hwp 로 저장합니다 — hwpx 를 hwp 로 바꾸거나 PDF 로 바꾸는 기능은 없습니다.

## 자주 헷갈리는 것

- **hwpx 파일 이름만 hwp 로 바꾸면 되나요?** 안 됩니다. 확장자는 이름표일 뿐이라, 이름을 바꿔도 안쪽은 여전히 hwpx 입니다. hwpx 를 못 읽는 프로그램은 이름을 바꿔도 못 읽습니다.
- **받는 쪽이 hwp 를 요구하면?** 한글에서 열어 「다른 이름으로 저장」 으로 hwp 를 고르는 것이 확실합니다. 한글이 없다면 보낸 쪽에 hwpx 로 내도 되는지 먼저 물어보세요.

휴대폰에서 여는 법은 [휴대폰에서 hwp 파일 열기](mobile), 맥에서는 [맥북에서 hwp 열기](mac) 를 보세요. hwpx 도 순서가 같습니다.
