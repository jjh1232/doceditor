학교 안내문, 동사무소 신청서, 채용 지원서는 아직도 hwp 로 오는 경우가 많습니다.
컴퓨터 앞이 아닐 때 휴대폰으로 받으면 「열 수 있는 앱이 없습니다」 가 뜨기 쉽습니다.
휴대폰에는 한글 프로그램이 기본으로 없기 때문입니다.

## 앱 없이 브라우저로 여는 순서

[hwp 열기·편집 도구](../ko) 는 앱이 아니라 웹 페이지라 설치할 것이 없습니다. 파일도 서버로 올라가지 않고 휴대폰 안에서 열립니다.

**아이폰**

1. 카톡·메일에서 받은 hwp 파일을 길게 누르거나 공유 버튼을 눌러 **「파일에 저장」** 합니다.
2. 사파리에서 이 도구를 엽니다.
3. 「hwp · hwpx · 一太郎 파일을 여기에 끌어다 놓으세요」 칸을 누르면 파일 고르는 창이 뜹니다. 방금 저장한 파일을 고릅니다.

**갤럭시(안드로이드)**

1. 카톡·메일에서 받은 파일을 내려받습니다. 보통 「내 파일 → 다운로드」 에 들어갑니다.
2. 크롬이나 삼성 인터넷에서 이 도구를 엽니다.
3. 파일 넣는 칸을 눌러 내려받은 hwp 를 고릅니다.

열리면 표와 글이 화면에 나타나고, 원래 비어 있던 칸은 노랗게 표시됩니다.

## 채워서 다시 보내기

1. 노란 칸을 눌러 내용을 적습니다. 이미 글자가 있는 칸도 고칠 수 있고, 체크 상자는 □ 를 ■ 로 바꿀 수 있습니다.
2. 아래 **「hwp 로 저장」** 을 누르면 `원래이름_작성.hwp` 로 저장됩니다.
3. 아이폰은 「파일 → 다운로드」, 갤럭시는 「내 파일 → 다운로드」 에서 찾아 카톡이나 메일로 다시 보내면 됩니다.

저장한 파일은 원본 구조를 그대로 두고 고친 칸만 바꾼 것이라, 받는 쪽이 한글에서 열면 원래 양식 그대로 나옵니다.

## 휴대폰에서 알아 둘 것

- **화면은 원본 배치를 흉내 낸 것**이라 줄 넘김 위치가 조금 다르게 보일 수 있습니다. 저장한 파일은 원래 배치대로 열립니다.
- 칸이 많은 양식은 휴대폰 화면에서 작게 보입니다. 두 손가락으로 확대해서 쓰면 됩니다.
- 보기만 할 거라면 한컴이 내놓은 뷰어 앱이나 네이버 웨일 브라우저의 문서 보기로도 열립니다. 다만 **보기만 되고 채워서 저장하기는 어렵습니다.** 빈칸을 채워 다시 보내야 할 때 이 도구가 필요합니다.
- 암호가 걸리거나 배포용으로 잠긴 문서는 열리지 않습니다.

hwp 말고 **hwpx** 로 온 파일도 같은 방법으로 열립니다. 차이는 [hwpx 파일 열기](hwpx) 에 정리했습니다.
