韓国の学校や会社、留学先や取引先から届いたファイルの拡張子が `.hwp` や `.hwpx` だった——
これは韓国で広く使われているワープロソフト **ハングル（한글）** の文書です。
日本でいう一太郎のような存在で、韓国の役所・学校・企業の書類はいまも多くがこの形式です。

## hwp と hwpx の違い

| | hwp | hwpx |
|---|---|---|
| 中身 | ハンコム社独自のバイナリ形式 | zip の中に XML 文書 |
| 位置づけ | 長く使われてきた標準形式 | 後から出た公開形式 |

見た目や内容は同じですが、ファイルの中身はまったく違います。
**古いハングルや hwp しか読めないビューアでは、hwpx が開けない** ことがあります。

どちらも Word やプレビュー、日本語のワープロでは開けません。

## ソフトなしで開いて記入する

[一太郎・HWP を開くツール](../ja) は、hwp と hwpx の両方を開けます。ブラウザだけで動き、ファイルはサーバーに送られません。

1. ファイルをドラッグするか、枠をクリックして選びます。「ハングル（HWP）文書です」のように形式が表示されます。
2. 元の様式で空欄だったところは黄色で表示されます。クリックして記入します。
3. 「**HWP で保存**」（hwpx なら「**HWPX で保存**」）を押すと、同じ形式で保存されます。

保存したファイルは、元のファイル構造をそのまま残して書き換えた欄だけを差し替えたものです。
相手がハングルで開くと、元の様式どおりに表示されます。

## できること・できないこと

- **hwp** — 空欄への記入、文字の修正、チェックボックス（□ → ■）、写真と手書き署名の挿入、行ごとの文字サイズ・行間の変更
- **hwpx** — いまは文字の記入のみ
- 形式の変換はしません。hwp は hwp、hwpx は hwpx のまま保存します。PDF や Word への変換機能はありません。
- パスワードや DRM で保護された文書は開きません。

一太郎の文書の開き方は [jtd ファイルの開き方](jtd) にまとめています。
