学校や自治会からのお知らせがメールで届いたら、添付が一太郎の `.jtd` だった——
スマホには一太郎を開けるアプリが入っていないので、「開けません」で止まってしまいます。

## ブラウザで開く手順

[一太郎・HWP を開くツール](../ja) はアプリではなく Web ページなので、インストールは不要です。
ファイルはサーバーに送られず、スマホの中で開かれます。

**iPhone**

1. メールや LINE の添付ファイルを長押しするか共有ボタンを押して「**"ファイル"に保存**」を選びます。
2. Safari でツールを開きます。
3. 「一太郎・HWP・HWPX ファイルをここにドロップ」の枠をタップすると、ファイルを選ぶ画面が出ます。保存したファイルを選びます。

**Android**

1. 添付ファイルをダウンロードします。ふつうは「ファイル → ダウンロード」に入ります。
2. Chrome でツールを開きます。
3. 枠をタップして、ダウンロードしたファイルを選びます。

## 記入して送り返す

1. 空欄をタップして記入します。
2. 一太郎の文書なら「**一太郎で保存**」を押します。`元の名前_記入.jtd` として保存されます。
3. iPhone は「ファイル → ダウンロード」、Android は「ファイル → ダウンロード」から探して送り返します。

一太郎の文書は、行の中の **元の空白の数まで** 記入できます。はみ出した行は赤く表示されるので、短く書き直してください。

## スマホで使うときの注意

- 画面の表示は元のレイアウトを再現したものなので、改行の位置が少し違って見えることがあります。保存したファイルは元のレイアウトのまま開きます。
- 表の多い様式はスマホでは小さく見えます。二本指で拡大して使ってください。
- パスワードで保護された文書は開きません。

韓国のハングル（`.hwp`・`.hwpx`）ファイルも同じ手順で開けます。詳しくは [hwp・hwpx ファイルとは](hwpx) を見てください。
