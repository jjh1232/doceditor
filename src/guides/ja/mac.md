Mac で `.jtd` ファイルをダブルクリックすると「この書類を開くアプリケーションがありません」と出ます。
一太郎は Windows 向けのソフトで、無料の **一太郎ビューアも Windows 専用** です。
プレビューや Pages、Mac 版 Word でも一太郎の文書は読めません。

## Mac での選択肢

- **Windows の環境を用意して一太郎を使う** — 仮想環境などが必要で、手間も費用もかかります。
- **送り主に PDF や Word で送り直してもらう** — 見るだけならこれがいちばん確実です。ただし記入して返す様式だと困ります。
- **ブラウザで開く** — [一太郎・HWP を開くツール](../ja) は Safari や Chrome だけで動きます。

## Safari・Chrome で開いて記入する

1. [一太郎・HWP を開くツール](../ja) を開きます。
2. Finder から jtd ファイルをドラッグします。クリックして選ぶか、Finder でファイルをコピー（⌘C）してページに貼り付け（⌘V）ても開けます。
3. 文書が表示されたら、空欄をクリックして記入します。
4. 「**一太郎で保存**」を押すと、ダウンロードフォルダに `元の名前_記入.jtd` が保存されます。

ファイルは Mac の外に出ません。読み込み・記入・保存はすべてブラウザの中で行われるので、
氏名や住所が入った書類を知らないサーバーに上げる必要はありません。

## 記入できる量について

一太郎の文書は、行ごとの文字の位置を内部で記録しています。
そのためこのツールでは、行の中の **元の空白の数まで** 書き込めます。はみ出した行は赤く表示されます。
写真・署名・文字の大きさの変更は、一太郎の文書ではまだできません。

## 韓国のハングル（hwp）ファイルも開けます

同じツールで、韓国のワープロ「ハングル」の `.hwp`・`.hwpx` ファイルも開けます。
韓国の学校や会社から届いた書類に困ったときは [hwp・hwpx ファイルとは](hwpx) を見てください。
