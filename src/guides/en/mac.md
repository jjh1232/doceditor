Double-click a `.hwp` file on a Mac and you get "There is no application set to open the document".
HWP is the format of Hangul, the Korean word processor, and neither Preview nor Pages nor Word can read it.

## Your options

| Option | View | Fill in and save as HWP | What you need |
|---|---|---|---|
| Hancom's Mac version of Hangul or Hancom Docs | Yes | Yes | A purchase or an account |
| Naver Whale browser's document viewer | Yes | Not really | Install Whale |
| [HWP viewer & editor](../en) | Yes | Yes | Safari or Chrome |

If you write HWP documents regularly, buying Hancom's software makes sense.
If you just need to **fill in the occasional form** — a school notice, a visa or job application — doing it in the browser is quicker.

## In the browser

1. Open the [HWP viewer & editor](../en) in Safari or Chrome.
2. Drag the `.hwp` file in from Finder. You can also click to choose it, or copy the file in Finder (⌘C) and paste it on the page (⌘V).
3. The tables and fields appear. Yellow fields are the ones that were empty in the original.
4. Fill them in and click **Save as HWP**. The file goes to your Downloads folder.

The file never leaves your Mac — reading, editing and saving all happen inside the browser.
For a résumé or an application full of personal details, that means nothing is sent to a server you do not know.

## What you can change

- Fill in empty fields, edit existing text
- Tick checkboxes (□ → ■)
- Change font size and line spacing, one line at a time
- Add a photo and a handwritten signature — see [sign an HWP form](signature)

You cannot write a new document from scratch, draw new tables or change the page layout. It is built for filling in forms you have been sent.

## Will it open properly in Hangul?

The tool keeps the original file intact and **writes only the changed fields back into place**.
Everything you did not touch stays byte-for-byte the same, so fonts, margins, table borders and headers set in Hangul are preserved.
The on-screen layout is an approximation and lines may sit slightly differently, but the person you send it to sees the original layout.
